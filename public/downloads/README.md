# IntellectMode Installers

These are placeholder files for the installer downloads. Replace them with actual built installers from electron-builder.

## To generate real installers:

```bash
npm run build-electron
```

This will create:
- `IntellectMode-Setup.exe` (Windows)
- `IntellectMode.dmg` (macOS)
- `IntellectMode-x86_64.AppImage` (Linux)
